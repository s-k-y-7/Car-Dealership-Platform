# Deployment & Local Setup Guide
## Premium Car Dealership Platform — Company A (Brand X Lucknow)

---

### 1. Prerequisites

Ensure the following tools are installed on your host system:
* **Python**: 3.10 or newer (tested on Python 3.12, 3.13, and 3.14)
* **Node.js**: 18.x or newer (tested on Node v20+ and v25+)
* **npm**: 9.x or newer
* **PostgreSQL**: Optional for local testing (the system dynamically falls back to SQLite3 with identical schema if PostgreSQL is not active)

---

### 2. Environment Variables Configuration

Copy `.env.example` to `.env` in the project root:

```bash
cp .env.example .env
```

| Environment Variable | Description | Default Value |
|----------------------|-------------|---------------|
| `DJANGO_SECRET_KEY` | Django cryptographic secret key | *Random secure string* |
| `DJANGO_DEBUG` | Enable debug mode for local development | `True` |
| `ALLOWED_HOSTS` | Comma-separated allowed hostnames | `localhost,127.0.0.1` |
| `DB_ENGINE` | Database backend engine (`postgres` or `sqlite`) | `postgres` |
| `DB_NAME` | PostgreSQL database name | `car_dealership_db` |
| `DB_USER` | PostgreSQL user | `postgres` |
| `DB_PASSWORD` | PostgreSQL password | `""` |
| `DB_HOST` | PostgreSQL host | `localhost` |
| `DB_PORT` | PostgreSQL port | `5432` |
| `GROQ_API_KEY` | Groq API Key for server-side AI integration | *(Optional — activates rule-based fallback if empty)* |
| `GROQ_MODEL` | LLM model identifier | `llama-3.3-70b-versatile` |
| `GROQ_API_URL` | Groq completions API endpoint | `https://api.groq.com/openai/v1/chat/completions` |

### 3. Step-by-Step Local Setup

#### Step 3.1: Backend Setup (Django & Database)

1. Create and activate a Python virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run database migrations:
   ```bash
   python backend/manage.py migrate
   ```

4. Seed the database with realistic demo inventory, showrooms, and users:
   ```bash
   python backend/manage.py seed_dealership
   ```

5. Run Django unit tests:
   ```bash
   python backend/manage.py test vehicles leads
   ```

6. Start the Django development API server:
   ```bash
   python backend/manage.py runserver 127.0.0.1:8000
   ```
   *The backend REST API is now listening at `http://127.0.0.1:8000/api/`.*

---

#### Step 3.2: Frontend Setup (React & Vite)

1. Navigate to the `frontend/` directory:
   ```bash
   cd frontend
   ```

2. Install npm dependencies:
   ```bash
   npm install
   ```

3. Build the production bundle to verify types:
   ```bash
   npm run build
   ```

4. Start the Vite development server:
   ```bash
   npm run dev
   ```
   *The user interface will be live at `http://127.0.0.1:5173/`.*

### 6. Production Deployment Architecture

In a production environment:

1. **Reverse Proxy (Nginx)**:
   * Terminates TLS/SSL.
   * Serves static assets generated by `npm run build` from `frontend/dist/`.
   * Proxies `/api/` and `/admin/` requests to Gunicorn.
2. **Application Server (Gunicorn)**:
   ```bash
   gunicorn dealership.wsgi:application --bind 127.0.0.1:8000 --workers 4
   ```
3. **Database Server**:
   * Managed PostgreSQL 15+ instance with SSL connections and automated backups.
4. **Environment Secrets**:
   * Securely injected via system environment variables, AWS Secrets Manager, or HashiCorp Vault.
